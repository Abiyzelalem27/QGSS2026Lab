# QGSS 2026 Lab

Python modules, tests, and notebooks for QGSS 2026.

## Project structure

- `src/qgss2026/` contains reusable Python modules.
- `tests/` contains automated tests.
- `notebooks/` contains the laboratory notebooks.

## Installation

Run:

    pip install -e ".[dev]"

## Testing

Run:

    pytest
